# Python calculator

A simple calculator project, built incrementally version by version.

## Version 1
- Takes 2 numbers and an operation (+, -, *, /).
- Perfoms the operation.
- Handles division by zero.

## Version 1.1
- While loop included.

## Version 1.2
- Added more kinds of operations (+, -, *, /, //, %, **).
- Added input validation using try/except to handle invalid number input.
